# Headers, Main and Footers

## What is it?
Semantic elements describe the role of each part of a page: `<header>` (top), `<main>` (main content) and `<footer>` (bottom). They make the page easier to read for people, search engines and screen readers.

## Syntax
```html
<header>...</header>
<main>...</main>
<footer>...</footer>
```

## Important attributes/properties
- `header` – intro, title, navigation
- `nav` – group of navigation links
- `main` – main content (one per page)
- `footer` – author, copyright, contact
- `hr` – separator line
- `mailto:` – email link
- `&copy;` – copyright symbol

## Examples
- `01-semantic-page.html` – complete page with header, nav, main, footer, author, copyright and email link
- `style.css` – simple layout styles

## Key takeaway
- Use semantic tags instead of many `<div>`s.
- Only one `<main>` per page.
- Put author, copyright and contact info in the footer.
