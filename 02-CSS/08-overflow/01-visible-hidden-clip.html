visible (default)
The text is longer than the box so it spills out of the box and shows below.
hidden
The text is longer than the box so the extra part is cut off and cannot be reached.
clip
The text is longer than the box so the extra part is cut off exactly like hidden, but no scrolling is ever possible.
clip + margin
The text is longer than the box so the extra part is cut, but 15px beyond the box is still visible.
