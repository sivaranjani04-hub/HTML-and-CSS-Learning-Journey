# CSS Borders

## What is it?
Borders are lines around an element. You control their style, width, colour and rounded corners.

## Syntax
```css
div {
  border: 3px solid crimson;
  border-radius: 10px;
}
```

## Important attributes/properties
- `border-style` – solid, dashed, dotted, double, groove, ridge, inset, outset, none
- `border-width` – thickness
- `border-color` – colour
- `border-radius` – rounded corners
- `border` – shorthand: width style color

## Examples
- `01-border-styles.html` – visual comparison of every style
- `02-width-color-radius.html` – width, colour, radius

## Key takeaway
- A border needs a style or it will not show.
- Shorthand: `border: 2px solid red;`
- `border-radius: 50%` makes circles.
