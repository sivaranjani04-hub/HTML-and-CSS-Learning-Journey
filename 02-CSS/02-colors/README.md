# CSS Colors

## What is it?
Colours can be written as names, RGB, HEX or HSL. `color` sets the text colour and `background-color` sets the background.

## Syntax
```css
p {
  color: white;
  background-color: rgb(63, 81, 181);
}
```

## Important attributes/properties
- `color` – text colour
- `background-color` – background colour
- `names` – `tomato`
- `rgb()/rgba()` – `rgb(255,0,0)`
- `HEX` – `#ff0000`
- `hsl()` – `hsl(0,100%,50%)`

## Key takeaway
- All four formats can describe the same colour.
- HEX is the most common in real projects.
- Use enough contrast between text and background.
