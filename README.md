# HTML-CSS-Learning

My personal notes for learning **HTML** and **CSS**. Every topic has its own folder with a README, small runnable examples, and any assets it needs, so I can revise each topic on its own.

## How to use
1. Open any topic folder and read its `README.md`.
2. Double-click an `.html` file (or use the VS Code *Live Server* extension) to see it in the browser.
3. Change the code and refresh to experiment.

## Folder structure
```
HTML-CSS-Learning/
├── README.md
├── 01-HTML/   (13 topics)
└── 02-CSS/    (24 topics)
```
Each topic folder contains a `README.md`, numbered example files, a `style.css` (or one `.css` per example in the CSS section) and an `assets/` folder when images, audio, video, fonts or icons are needed. All paths are relative, so every topic works independently.

## Notes about assets
- Images, audio, video and favicons are small files generated for this project, so they carry no licence restrictions. Replace them with your own files, keeping the same names.
- `02-CSS/03-fonts/assets/fonts/Pacifico-Regular.ttf` is the Pacifico font (SIL Open Font License).
- `02-CSS/21-icons/assets/fontawesome/` contains Font Awesome Free (see the licence file in that folder).
- A few examples need internet: external links, Google Fonts, and the POST examples that submit to `httpbin.org`.
